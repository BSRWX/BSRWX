### 🔭 What I'm currently working on:
- **Slavenia (MMORPG):** A 2D Slavic-mythology co-op game in Unity, featuring a custom C# .NET TCP/UDP server architecture and binary packet protocols.
- **Motorsport Telemetry System:** A modular hardware-in-the-loop (HIL) telemetry logger using ESP32-S3 & NXP MCX, communicating via CAN-bus to a custom .NET MAUI dashboard.
- **Home Server Architecture:** Building an Android app (Kotlin Jetpack Compose) connected to an ASP.NET Core backend to monitor and manage my local Ubuntu Linux server setup.
- **Personal Portfolio:** Designing my developer portfolio using React, Vite, and Tailwind CSS v4.

### 🌱 What I'm currently exploring:
